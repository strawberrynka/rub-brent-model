# Доработка проекта для портфолио

Исходная версия: fc13f0739de7b385a53c736493d1d897574acf7f.

- Удалено правило .gitignore, исключавшее report_generator.py; генератор восстановлен.
- Запуск по умолчанию работает без сети; обновление данных является явным действием.
- Зафиксировано окружение Python 3.12, добавлены проверки и GitHub Actions.
- Добавлены контроль покрытия календаря, дубликатов и положительности, защита от
  разностей через пропущенные годы. Неполный 1992 год исключён.
- Сравнение моделей изменений переведено на общую выборку; модель уровней вынесена
  отдельно. Добавлены AR(1) без нефти и основная модель AR(1) с текущим Brent.
- Добавлены HAC-интервалы с явной поправкой малой выборки, Breusch-Godfrey,
  проверки начала выборки, числа лагов HAC и влияния отдельных наблюдений.
- Тест коинтеграции включён в pipeline с записью порядка рядов и настроек.
  Исходные p≈0.000002 и p≈0.7184 воспроизводились при перестановке рядов.
  Новая выборка и явные фиксированные лаги дают другие результаты;
  чувствительность показывается, а не скрывается выбором удобного теста.
- Текстовые результаты макроэкономических моделей, отсутствующих в коде и данных,
  убраны из текущих доказательств.
- Markdown и PDF теперь используют один источник содержания и таблиц.
  Кириллица работает через шрифты matplotlib независимо от ОС.
- Удалены устаревшие копии отчётов и графиков; исходные материалы доступны в истории Git.
- Добавлен исследовательский ноутбук и краткий README с авторами исходной работы.

Изменение чисел относительно исходной версии ожидаемо: изменились граница выборки,
общая выборка сравнения, набор моделей и поправка стандартных ошибок.
Это не улучшение метрик на прежних условиях, а исправление условий сравнения.
