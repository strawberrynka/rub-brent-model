# Материалы для защиты проекта

В папке `final_materials` находятся дополнительные материалы к проекту.

## Список файлов

### `01_detailed_explanation.md`

Подробное простое объяснение проекта: данные, подготовка, переменные, тесты, модели и выводы.

### `02_teacher_report.md`

Формальный отчет для преподавателя с постановкой задачи, методологией, результатами и ограничениями.

### `03_presentation.pptx`

Презентация для устной защиты проекта.

### `04_slide_speech_text.md`

Текст выступления по каждому слайду презентации.

## Как использовать

1. Перед защитой прочитать `01_detailed_explanation.md`.
2. Для сдачи преподавателю использовать `02_teacher_report.md`.
3. Для выступления открыть `03_presentation.pptx`.
4. Во время подготовки к выступлению использовать `04_slide_speech_text.md`.

## Примечание о версии проекта

Текущая версия проекта содержит расширенные модели `model_4` и `model_5`, HAC-ошибки и таблицу `stationarity_tests.csv`. Поэтому материалы описывают не только первые три базовые модели, но и улучшенную спецификацию, которая стала лучшей по AIC.
